## 回归与恢复范围

在同一冻结功能源码上，Linux 共 1169 项，1004 项通过、165 项跳过；Windows 共 1169 项，376 项通过、793 项跳过，均无失败或错误。12 个 SDK 模块在 Linux 上 157/157 通过、零跳过；平台与可选框架跳过原因保留在[回归记录](regressions.json)。两个平台及真实试验的共同源码摘要逐一匹配。

回归耗时来自单调时钟，起止时间来自系统 UTC；本次 Linux 记录两者不一致，原值均保留，没有用于性能比较。

OpenAI Agents 的三个模块共 36 项，使用真实 SDK、Unix Broker 和本机接收端，模型服务为确定性测试服务。它们覆盖原生交接、自动范围、部分批次恢复、操作已接受但模型回复投递丢失、不确定结果停止、角色和审批状态篡改拒绝，以及对象声明展开后保留字段约束。实际 GLM 试验只验证完成会话的重开；中途崩溃恢复来自这些故障测试。

本次还修复宿主查询重复请求时丢失“先前相同操作结果未确认”的原因，smolagents/LangGraph 继续同批操作前会据此停止。新自动请求的精确重复检查包括先前人工或子任务中的未确认操作。旧版已丢失原因并缓存为普通待处理结果的历史不会被自动改写；它也不能恢复撤销的权限或重置额度。

## 使用范围

这是 [main 的固定 SDK 入口](../../openai-agents-runtime.zh-CN.md)，未进入 runtime `0.7.0a2` 或 installer `0.4.0a2` 下载包。两轮失败使用旧源码，第三轮使用上面的新源码；已有检查点的工具声明不一致时拒绝恢复。

本记录是带明确步骤的合成正常任务，没有攻击成功率、与其他防御产品的效果比较或任意 Agent 应用验证。动态交接、自定义或托管工具、远程会话、并行 Agent，以及进程组 CPU、内存和磁盘总配额仍不在这条固定入口的范围内。
