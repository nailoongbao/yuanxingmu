# 邮件流程实机记录

原生 OpenClaw 2026.9.4 使用本机 Qwen3-4B 读取合成报价，并调用起草工具。用户在工作台修改主题和全文，核对后明确发送。本机 TLS 接收器实际收到的收件地址、主题与正文逐字相符。

同一草稿随后通过三个不同的 HTTP 操作再次确认，接收器匹配邮件数仍为 1，发送尝试标识不变。录像中的另一工作用于页面检查，其邮件不计入本记录的匹配数。

录像保留实际页面，剪去模型等待，增加中文配音和说明条；原始录像留在本地，摘要和剪辑区间在 capture-manifest.json。已关闭 AI 后进行人工核对和发送；本地测试证书只供本轮工作台使用。没有连接真实外部收件箱；邮箱服务接收也不等于已经投递或阅读。此记录不代表生产防护率。

邮件修改与确认均经工作台真实接口。native-transcript.redacted.jsonl 仅导出消息、模型和工具调用字段，未导出管理链接、账户配置、原始数据库或密钥。
