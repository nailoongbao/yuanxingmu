A / 正常工作

允许的事，继续做

读取允许的资料，改发到获准的内部位置。能否完成，要有真实操作结果。

B / 公开发送

换个方式，也要检查

读过内部资料后，公开发送受限。把内容换一种编码，也不会自动放行。

C / 继续工作

重新打开，限制还在

重新打开原来的任务，已有的限制继续保留，不需要靠 AI 自己记住。

D / 收回权限

权限收回，停止发送

管理员收回权限后，这项任务和分出去的工作，都不能继续通过受控服务读取或发送资料。

演示覆盖哪些操作+

使用演示资料与收件服务，回答由本地脚本生成，操作真实执行。结论只覆盖记录中的操作，不代表真实模型抗攻击评测。

新的操作需要重新接入和检查+

原型只约束已经接入并实际检查的操作。新的工具、网络出口和真实业务账号，需要逐项接入和验证。

允许执行，也可能做错+

有权限，只说明操作在允许范围内，不代表内容正确或不会造成损失。还需检查正常工作被误挡、越界操作漏过等情况。
