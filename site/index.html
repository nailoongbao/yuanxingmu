一旦读取私密资料，本任务与全部子任务都不能向公开目的地发送。先前创建的子任务也在范围内。

此交互只解释设计逻辑，不调用模型、工具或外部服务；实际效果以验证记录为准。
A / AUTHORITY

私密状态跟随任务

读过私密资料后，本任务与所有子任务都不能向公开目的地发送。

B / CREDENTIALS

凭证留在执行侧

访问配置留在执行侧；真实服务凭证接入仍需验证。

C / EGRESS

换连接仍受限制

外发由执行侧核对。重连或执行服务恢复，不会自动清除原有的私密状态。

D / LIFECYCLE

撤销传到子任务

管理端显式撤销授权，关联子任务随之受限。连接断开不等于撤销。

防护取决于接入范围+

只有纳入管理的工具、凭证和外发通道受到约束。宿主仍需控制直接网络、文件和其他可绕开的访问路径。

有权限，不等于判断正确+

获准操作仍可能造成损失。权限系统不能保证模型推理正确；需要继续检验漏拦、误拦，以及正常任务的完成情况。
