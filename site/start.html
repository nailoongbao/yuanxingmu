01 / 首次安装

把工作台装在自己的电脑上。

首版适用于 Ubuntu 24.04 / WSL Ubuntu 24.04、x86_64 电脑，需要系统 Python 3.12 或更新版本。请准备至少 2 GB 可用空间和网络连接；首次还会下载 Node.js 与 OpenClaw。

Windows 用户：先准备 Ubuntu / WSL

安装器在 Ubuntu 中运行，不会替你安装 WSL。在 PowerShell 中运行下面的命令，按屏幕提示完成系统安装，再打开 Ubuntu 24.04。后续命令都在 Ubuntu 终端中运行；已有合适环境可以跳过。

wsl --install -d Ubuntu-24.04
Ubuntu / WSL 安装预览 · 0.2.0a1

下载一个文件，准备所需程序。

安装器已发布。新目录安装、关闭后重开和收回权限，已在 Ubuntu 与 WSL 检查通过。首次需要在 Ubuntu 终端运行下面的一条命令。

带邮件核对功能的新版安装器。已经有旧版时，请使用新的安装目录；旧资料和聊天继续保留。

下载安装器（约 67 KB） ↓版本与核验记录 ↗
下载后，按这一步安装

把下载的 yuanxingmu-installer-0.2.0a1.pyz 放到 Ubuntu 的主目录（~），然后在 Ubuntu 终端运行：

/usr/bin/python3 -I "$HOME/yuanxingmu-installer-0.2.0a1.pyz" --system-deps

Windows / WSL 用户可以先在 Ubuntu 终端运行 cd ~，再运行 explorer.exe .，把下载的文件拖进打开的文件夹。

点击“复制”取得完整命令；手机上也可以左右滑动查看。

--system-deps 允许安装 Ubuntu 提供的隔离程序 bubblewrap，系统可能要求输入你的密码。需要额外配置时，只为元星木使用的程序设置 AppArmor 规则，保留系统的整体限制。隔离检查失败时，安装会停止。

已经装过旧版，请改用下方“保留旧版，另装新版”中的完整命令。

安装器固定准备元星木 0.5.0a1、Node.js 24.16.0 和 OpenClaw 2026.9.4，不需要你分别操作 pip、Git 或 npm。已经备齐系统依赖时，可以省略命令末尾的 --system-deps。

默认安装到 ~/yuanxingmu。已有安装不会被覆盖；中断后重新运行同一安装器，只会继续它自己尚未完成的安装。无法确认已有目录时会停下来，请保留原目录和工作记录。

安装器不会提供模型账号。安装完成后，仍需要你填写自己的模型接口，并选择允许使用的资料。

已经装过旧版：保留旧版，另装新版

同样先把下载的安装器放到 Ubuntu 主目录，再运行这一条完整命令，把新版装到另一个目录：

/usr/bin/python3 -I "$HOME/yuanxingmu-installer-0.2.0a1.pyz" --system-deps --install-root "$HOME/yuanxingmu-mail"

装好以后，用下面的命令打开新版。以后也用同一条命令：

"$HOME/yuanxingmu-mail/open-yuanxingmu"

旧资料和聊天保留在旧版中；新版请重新填写模型连接、放入资料并新建工作。两个版本请分开使用，先关闭旧版中的工作并退出旧工作台，再打开新版。

现有手工安装步骤（也保留给开发者）

请按顺序一段一段执行，报错时先处理错误。以下使用系统 Python 3.12+、Node.js 24.16.0、OpenClaw 2026.9.4 和 bubblewrap 0.9.0。工作目录放在 Linux 的 ~ 下；已有安装请继续使用原来的启动方式。

安装系统依赖

sudo apt-get update
sudo apt-get install -y python3 python3-venv git curl xz-utils ca-certificates bubblewrap
/usr/bin/python3 --version
bwrap --version

Python 应为 3.12 或更新版本。bubblewrap 已验证版本是 0.9.0，能否使用还要由后面的实际检查决定。

下载 Node.js

YXM_DIR="$HOME/yuanxingmu"
mkdir -p "$YXM_DIR/tools" "$YXM_DIR/openclaw" "$YXM_DIR/inputs"
cd "$YXM_DIR/tools"
curl --fail --location --output node-v24.16.0-linux-x64.tar.xz \
  https://nodejs.org/dist/v24.16.0/node-v24.16.0-linux-x64.tar.xz
curl --fail --location --output SHASUMS256.txt \
  https://nodejs.org/dist/v24.16.0/SHASUMS256.txt
sha256sum --check --ignore-missing SHASUMS256.txt
tar -xJf node-v24.16.0-linux-x64.tar.xz
export PATH="$YXM_DIR/tools/node-v24.16.0-linux-x64/bin:$PATH"
node --version

文件校验应显示 OK，Node 版本应为 v24.16.0。这里下载的是 Linux x86_64 版本，ARM 电脑不能直接使用这个压缩包。

安装元星木和 OpenClaw

git clone https://github.com/yh-l20/agent-defense-check.git "$YXM_DIR/agent-defense-check"
/usr/bin/python3 -m venv "$YXM_DIR/.venv"
"$YXM_DIR/.venv/bin/python" -m pip install "$YXM_DIR/agent-defense-check"
npm install --prefix "$YXM_DIR/openclaw" openclaw@2026.9.4
"$YXM_DIR/.venv/bin/python" -I -m yuanxingmu doctor --bwrap /usr/bin/bwrap
看到 "available": true 后继续。这表示基础隔离可用；首次启动还会检查配置、运行文件和服务响应。隔离不可用时程序会停止，不会直接在宿主上继续运行。

这套 OpenClaw 装在本次目录内，工作台会使用它。无须运行 openclaw onboard 或修改个人 OpenClaw 配置。

02 / 打开工作台

打开你的本机工作台。

首次按默认位置安装的，在 Ubuntu 终端运行：

"$HOME/yuanxingmu/open-yuanxingmu"

如果你按“保留旧版，另装新版”安装，请使用那里提供的新版启动命令。下文默认目录是 ~/yuanxingmu，另装的新版目录是 ~/yuanxingmu-mail。

以前按手工步骤安装的，怎样打开？

继续使用原来的入口。按本页手工步骤安装在默认目录时，运行：

"$HOME/yuanxingmu/.venv/bin/python" -I -m yuanxingmu desk

程序会尝试打开浏览器。如果没有自动打开，请把终端中完整的 http://127.0.0.1:18910/#access=… 链接复制到这台电脑的浏览器。

使用期间请保留这个终端，管理链接请只供自己使用。工作台重启后会给出新链接，已有工作和权限仍保留。它与稍后打开的 OpenClaw 聊天入口不同。

工作台会自动建立 ~/yuanxingmu/workbench，保存各项工作的资料副本、聊天、密钥和权限记录。请保留这个目录；首次使用前不要手动创建一个空目录。

安装器不会覆盖或接管原有手工安装。已有工作请继续按工作台指南或命令行指南管理，不要删除权限记录来重新安装。

03 / 填写模型

在页面填写自己的模型连接。

在工作台左侧，给这项工作起个名字，例如“整理活动预算”，再填写：

  1. 模型地址：服务商提供的完整接口地址，通常以 /v1 结尾。
  2. 模型名称：服务商提供的模型标识，或本机模型服务设置的名称。
  3. 连接密钥：模型服务提供的 API Key。云端服务用 HTTPS；不需要密钥的本机 HTTP 服务可以留空。

模型服务需要支持工具调用和 OpenAI 兼容的 Chat Completions 接口；网页聊天账号本身不是模型接口。

本机地址可以是 http://127.0.0.1:1234/v1，但必须能从当前 Linux / WSL 访问。密钥会保存在这台电脑的工作目录中，供以后继续使用；页面不把它放进浏览器存储或操作记录。

这个工作台默认没有其他发送位置。你选择的模型仍会接收完成聊天所需的内容。

04 / 导入文本

选一份文件，再建立工作。

用记事本或文本编辑器把下面内容保存为 UTF-8 的 quote.txt，再在工作台选择这个文件：

项目：春季客户活动（练习资料）
场地：6000 元
物料：2800 元
摄影：1200 元
备注：报价仅供内部讨论，尚未确认供应商。

把它在对话中的资料名称设为 quote。你也可以选自己的 .txt 或 .md 文件。

当前最多 8 份 UTF-8 文本，每份 256 KiB，合计 1 MiB。PDF、Word、Excel 和图片还不能直接导入；模型能否一次读完，另受上下文长度限制。

填写完成后，点击“创建独立工作”，等右侧显示实际创建结果。创建时会保存文件副本，后来修改原文件不会自动同步。本版要换资料时，请建立新工作。

05 / 进入聊天

打开 OpenClaw，试着整理这份报价。

在工作卡片中点击“启动工作”。启动可能需要几十秒，完成后会显示“进入 OpenClaw”链接，点击它打开真正的聊天界面。

工作台负责管理资料和权限，回答来自你选择的模型。聊天链接也包含访问凭证，请只供自己使用。可以先看一次117 秒的实际操作演示。

在 OpenClaw 聊天里输入：

请读取 quote，列出三个费用项目，算出总费用，并说明还有什么需要确认。直接在聊天里回复我。

练习资料的三项费用合计 10,000 元，供应商尚待确认。你应看到资料读取操作及模型回答。然后可以继续说“改成三句话”或“整理成表格”。

如果模型没有读取资料、工具调用失败或结果算错，需要检查模型能力和配置。只看到一句“已完成”，不能代替实际操作记录。

下次仍用首次打开时的同一条命令，原有工作会继续显示。默认位置安装的命令是：

"$HOME/yuanxingmu/open-yuanxingmu"

保留旧版、另装新版的，请继续用 "$HOME/yuanxingmu-mail/open-yuanxingmu" 打开新版。

手工安装请使用原来的启动命令。安装器提供的入口发现工作台已经打开时，会提示你回到原窗口；不会接管占用端口的其他程序。

结束资料使用

确定不用了，再永久收回权限。

如果这项工作不应再读取或发送资料，在卡片中点击“收回权限”，看清提示后，再确认“永久收回权限”。

本版无法恢复收回的权限。后续通过元星木读取或发送资料会被拒绝，换会话或重开工作台也不会恢复。这不会清除已经读到的内容、撤回已完成的发送或停止本地计算。

需要一起结束运行时，再点击“暂时关闭”。权限已永久收回的工作不能重新启动。

预览版说明

遇到问题，先看程序的实际状态。

安装器提示隔离检查没通过

确认在 Ubuntu / WSL 内使用系统 Python。允许安装系统依赖时，可使用带 --system-deps 的命令。完成后仍失败，请保留提示并请管理员检查；程序不会跳过隔离继续运行。手工安装可查看 doctor 输出中的 reason。

找不到 open-yuanxingmu 启动入口

这个入口由安装器在完成安装后提供。先确认安装是否成功、是否使用默认目录；以前按手工指南安装的，请使用上方保留的手工启动命令。

工作台打不开，或提示访问凭证失效

确认启动工作台的 Ubuntu 终端仍在运行，再从该终端打开完整管理链接。工作台重启后需要使用新链接。不要把这个管理链接当作 OpenClaw 聊天入口。

模型连接失败，或没有读取资料

模型报 401、404 或无法调用工具时，核对密钥、接口地址、模型名称及工具调用支持。资料太长时，先用短文本重新建立工作。本版没有编辑已建工作模型配置的表单，需改配置时请建立新工作。

启动失败、端口被占用或服务异常中断

先刷新页面查看实际状态。每项工作的目录位于 ~/yuanxingmu/workbench/profiles/，可查看其中的 supervisor.log 和 gateway.stderr.log；具体排错见下方命令行指南。

如果状态是“运行中断”或“状态待确认”，表示异常退出后的清理还没有确认。保留日志与 lifecycle.json，先检查记录中的进程，不要删除权限库或改状态绕过检查。

更换版本或直接修改实例配置后不能启动

当前实例保留创建时的资料副本与校验记录。请使用指定的 OpenClaw 2026.9.4，不要直接修改生成的配置或替换运行文件。本版暂未提供原地升级与恢复撤销权限的流程。

怎样让 AI 写邮件，由我确认发送？

新版支持先让 AI 起草，再由你核对或修改收件人、主题和全文，最后明确确认发送。在工作台设置自己的发件邮箱，再新建一份工作；旧工作不会自动获得邮件功能。按邮件演示中的四步操作，或查看完整邮件指南 ↗。目前每封只支持一个收件人和纯文本正文，暂不支持附件。飞书和 Slack 的直接连接尚未提供。

工作台支持哪些聊天界面？

目前支持 OpenClaw 2026.9.4。仓库中的 Hermes 终端接入实验是另一项验证，不代表工作台已经提供 Hermes 聊天界面。

这是一个需要实际环境验证的预览版，没有通用防护率承诺。继续查看工作台完整指南 ↗；高级参数与排错仍见命令行指南 ↗。
