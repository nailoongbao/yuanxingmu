# 元星木 · 静态官网初稿

原创品牌与响应式研究预览页。无框架、远程字体、统计脚本或表单提交；所有图形由本地 SVG 与 CSS 绘制。

在仓库根目录预览：

```sh
python -m http.server 8767 --bind 127.0.0.1 --directory site
```

然后打开 `http://127.0.0.1:8767`。也可以直接打开 `index.html`，主体与机制交互无需网络；复制地址功能受浏览器剪贴板权限约束。

## 内容边界

首屏标记 **Research preview / 本地原型**。根任务报告本地原型已完成合成数据与真实进程验证，因此页面同步该阶段；原生框架接入仍在验证。具体结果链接至已公开的核心报告。机制交互是静态模拟，不调用模型或执行服务。没有生产防御率、覆盖数量或竞品优势声明。

`evidence-data.js` 是根任务的真实结果入口。已按根任务公开报告填写五类本地观察，`published: true` 显示公开证据链接。将来若记录尚未公开，应设为 `false`，使状态保留为“待公开核验”。每条记录支持 `pending` / `observed` / `partial`，且需 HTTPS 证据链接。发布时应说明具体版本、环境、正常任务结果及限制；不要把原有接入实验当成新版内核的证据。

文案与当前核心对齐：显式撤销由管理端发起，不暗示 TTL、自然结束或断线自动撤销；私密读取限制本任务和全部子任务的公开外发，重连或恢复不清除该状态。真实服务凭证接入仍标为待验证。

仓库链接指向当前真实公开项目 `yh-l20/agent-defense-check`。当前安装说明与新版权限核心明确区分。
